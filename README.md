# Sitio académico — Evaluación y RED

Plantilla web informativa para publicar en GitHub Pages.

## Estructura

- `index.html` → Inicio
- `modelos-evaluacion-red.html` → Página principal de Modelos de evaluación y RED
- `seleccionando-modelos.html` → Subpágina 2.1
- `recursos-educativos-digitales.html` → Subpágina 2.2
- `rediseno.html` → Rediseño
- `aplicacion-modelo.html` → Aplicación de modelo de evaluación
- `referencias.html` → Referencias
- `styles.css` → Estilos generales
- `script.js` → Menú desplegable y menú móvil
- `assets/logo-udes.png` → Logo con fondo transparente

## Publicación en GitHub Pages

1. Cree un repositorio en GitHub.
2. Suba todos los archivos conservando la estructura de carpetas.
3. En GitHub, entre a **Settings → Pages**.
4. Seleccione la rama que contiene `index.html` y la carpeta `/ (root)`.
5. Guarde la configuración y espere la publicación.
6. La página principal será `index.html`.

## Personalización

Busque los textos entre `[corchetes]` y reemplácelos por la información de su actividad.

Para añadir enlaces, cambie por ejemplo:

`href="#"`

por:

`href="https://ejemplo.com"`

El submenú se despliega al pasar el mouse sobre «Modelos de evaluación y RED». Al hacer clic sobre ese menú se abre `modelos-evaluacion-red.html`. En dispositivos táctiles, el comportamiento se adapta al menú móvil.
